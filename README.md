# Enterprise Hybrid Cloud Infrastructure

Capstone-style project designing and deploying a hybrid cloud infrastructure spanning two enterprise sites — combining on-premises virtualization with secure inter-site connectivity.

## Overview

Built a multi-site enterprise environment from the ground up: virtualized servers, centralized identity and file services, routed and segmented networks, and perimeter security — then validated the whole thing end to end.

## Technologies

- **Virtualization:** Proxmox VE
- **Firewall / Routing:** pfSense
- **Servers:** Windows Server, Linux virtual machines
- **Networking:** OSPF, VLANs, VPN
- **Services:** Active Directory, DNS, DHCP, DFS Replication, file / web / deployment servers
- **Validation:** Wireshark, network troubleshooting tools

## What was built

- Deployed and managed virtual machines, virtual storage, and backup routines across two sites
- Implemented **OSPF routing**, **VLAN segmentation**, firewall rules, and **VPN connectivity** between sites
- Hardened the environment with network security policies across the infrastructure
- Configured **Active Directory** with DNS and DHCP services for centralized identity and name resolution
- Set up **DFS Replication**, file servers, web servers, and deployment servers
- Performed end-to-end network validation with Wireshark and structured troubleshooting

## Skills demonstrated

Hybrid cloud design · Virtualization (Proxmox VE) · pfSense firewall administration · OSPF & VLAN configuration · Site-to-site VPN · Windows Server & Active Directory · DNS/DHCP · Linux systems · Packet analysis with Wireshark
